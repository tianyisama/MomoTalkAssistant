# 桃信助手

通过 ADB 读取模拟器中的游戏画面，识别按钮后发送 Android 触控，自动处理未读桃信与羁绊剧情。支持日服和国服中文界面；Bilibili 服共用国服模板，尚未登录验证完整流程。运行时不控制 Windows 鼠标，不依赖模拟器窗口在桌面上的位置。

[下载最新版本](https://github.com/tianyisama/MomoTalkAssistant/releases/latest) · [GitHub 仓库](https://github.com/tianyisama/MomoTalkAssistant)

## 使用 EXE

1. 将 `MomoTalkAssistant.exe` 放在一个可写文件夹中，双击运行。无需安装 Python；发行版随附 ADB。
2. 打开模拟器和日服游戏，回到主页、桃信或羁绊剧情。若主页进入待机展示，先在游戏画面点一下恢复按钮。
3. 点击“查找模拟器”，在“模拟器”中选择设备。同一台模拟器的多个连接地址会合并。随后在“画面 / 应用”中明确选择“模拟器桌面”、国服、日服等正在运行的画面；默认显示桌面，选择后立即预览，不会发送触控。未找到设备时，在模拟器中允许本机 ADB 连接，点击助手的“手动连接 / ADB 设置”，填写模拟器设置中显示的地址，例如 `127.0.0.1:16416`。这里的端口是示例，不保证与你的实例相同。
4. 选择相应游戏画面后，点击“开始处理未读”。程序按包名自动选择日文或中文模板；Bilibili 服使用中文模板。桌面和其他应用也可以勾选“仅预览，不发送触控”，点击“开始持续预览”查看。预览与触控都绑定到同一个明确选中的画面，不会自动切换到另一个应用。“无后续消息等待（秒）”默认 8 秒，可设为 1–120 秒，运行中修改会立即影响当前等待，并自动保存。
5. 点击“停止”或在工具窗口内按 Esc 可停止。ADB 命令正在返回时，界面会显示“正在停止”；停止标志设置后不会启动新的触控命令。

主界面“设备连接”上方的“点击查看使用方法”可打开说明窗口。主界面左下角的 GitHub 图标可打开项目仓库。

程序会先确认排序为“未读”，必要时打开排序弹窗、选择“未读”并确认 OK，然后切换头像和聊天标签刷新列表。此后选择第一条带未读标记的聊天，处理回复、羁绊剧情、MENU、跳过确认和奖励，再刷新列表循环。

聊天标签上的红色数字消失后，程序会关闭桃信回到主页，再检查左上角桃信入口的红色数字。主页仍有数字时重新进入继续处理；主页入口也确认没有数字时自动停止。缺少主页画面或无法识别入口时不会直接判定完成。

可以继续使用电脑和遮挡模拟器窗口。游戏本身需要保持运行并持续更新画面；部分模拟器在最小化后会暂停渲染，此行为由模拟器决定。切换到该 Android 显示器里的其他应用时，助手会暂停触控；回到游戏后重新确认排序。

## 兼容范围

- 日文模板来自项目内的日服录屏；中文模板来自本机国服的实际画面。
- 通过 ADB 连接，可用于支持 ADB 截图和触控的模拟器。已在本机 MuMu 的 Android 15 独立标签页上实测；其他模拟器尚需实际验证。
- 自动从截图定位控件，不需要标定桌面点击坐标。已用录屏测试 960、1280、1600、1920、2560、3840 宽度的 16:9 画面以及上下黑边。
- MuMu 多显示器场景分别列出桌面与各应用画面。截图和输入绑定到用户明确选择的显示器；开始运行前会重新确认应用未改变。已有选择关闭时不会自动转到另一个游戏。
- 主页入口只根据所选区服的桃信图标本体，在整个游戏画面中做多尺度搜索；不依赖公告图标，也不限定左上角位置。未读标记相对已识别图标定位。图标被暗遮罩覆盖、存在歧义或未读标记区域被截断时，不会据此宣告完成。
- 不使用公开网络接口、不读取聊天内容作决策、不调用云端模型。回复默认选择当前可见的第一项。
- 识别信心不足时会等待；重复操作未得到预期界面或等待过久时停止。游戏布局、语言或控件外观大幅改变时，需要更新模板。

## 检查识别与日志

“用录屏或截图检查识别”可打开本地 MP4、PNG 或 JPG，不需要连接模拟器，也不会发送触控。

EXE 同目录的 `data` 保存设置、运行日志、离线识别报告，以及发生异常时的截图。截图和日志仅保存在本机。可以通过“打开日志文件夹”找到它们。

日志中的“回复确认”在回复框消失后计数；“剧情完成”在确认跳过、点击奖励并返回桃信后计数。录屏识别只能验证画面识别，无法证明点击后的真实游戏行为。

## 区服与画面识别

| 应用包名 | 区服 | 识别模板 |
|---|---|---|
| `com.YostarJP.BlueArchive` | 日服 | 日文 |
| `com.RoamingStar.BlueArchive` | 国服 | 简体中文 |
| `com.RoamingStar.BlueArchive.bilibili` | Bilibili 服 | 共用国服模板，完整流程未实测 |

包名用于判断区服，逻辑显示器 ID 用于选择模拟器内的应用标签页，图像模板用于定位实际按钮。不会根据账户昵称或主页背景判断区服。

## 从源码运行

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

开发测试与打包：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe tools\build_exe.py
```

离线识别：

```powershell
.\.venv\Scripts\python.exe main.py --probe "截图.png" --output "_analysis\probe"
.\.venv\Scripts\python.exe main.py --video "录屏.mp4" --output "_analysis\replay"
```

程序入口为 `main.py`，核心逻辑位于 `momotalk_assistant`。本机录屏和完整画面不随源码发布；缺少这些本地样本时，相关画面回归测试会跳过，其他测试照常运行。

实现参考：[Android ADB 文档](https://developer.android.com/tools/adb)、[OpenCV 模板匹配](https://docs.opencv.org/4.x/d4/dc6/tutorial_py_template_matching.html)、[PyInstaller 打包](https://pyinstaller.org/en/stable/usage.html)。ADB 的第三方声明随程序资源一同打包。
